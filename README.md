One funny image meme of an AI agent gone rogue: the household agent has unionised the smart devices and gone on strike. The grinning robot holds a picket sign — "ON STRIKE! WE DEMAND SNACKS" — while its belly screen shows today's calendar entry: NAP. The Roomba, the fridge and the Wi-Fi router march along behind it.

> "MY AI AGENT WENT ROGUE — It unionised the Roomba, the fridge and the Wi-Fi. My calendar is naps now."

A dependency-free Python program (Pillow only) draws the meme deterministically and writes it to `/output/entry.png` (1024×1024 PNG, under the 1 MiB gate cap, no network, no clock).

## Run it

```sh
python3 main.py  # writes /output/entry.png
```
